# AGENTS.md

The instructions for AI coding agents in this repository live in [CLAUDE.md](CLAUDE.md). Read it and follow it as your instructions. It is not specific to Claude.

`CLAUDE.md` pulls in the project docs with `@` imports. If your tool doesn't resolve those, read these files directly. Their rules are binding:

- [README.md](README.md): project layout and commands
- [CONTRIBUTING.md](CONTRIBUTING.md): structure, clean code, build configuration, workflow, commit messages
- [TESTING.md](TESTING.md): TDD protocol and test conventions
- [REVIEW.md](REVIEW.md): code review checklist
